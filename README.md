# SDGoku

Судоку, в котором вместо цифр стоят иконки 17 целей устойчивого развития (ЦУР). В каждой игре участвуют 9 случайных целей из 17.

Версия 0.1.0. Языки: русский, английский, азербайджанский.

## Что уже работает

- Генератор головоломок с единственным решением, 4 уровня сложности (45 / 36 / 30 / 25 открытых клеток).
- Головоломка дня: одна на всех, зависит от даты; серия дней подряд.
- Заметки, отмена хода, стирание, 3 подсказки на игру, лимит в 3 ошибки, таймер и пауза.
- Автосохранение текущей игры и прогресса на устройстве.
- Статистика, 13 достижений, личные рекорды, карточки с описанием целей.
- Звук и вибрация (отключаются в настройках), светлая и тёмная тема по настройке системы.
- Серверный модуль (Firebase): вход по почте, синхронизация прогресса между устройствами, общий рейтинг, удаление аккаунта. **Выключен, пока не задан конфиг** (см. раздел «Сервер»).

## Сборка под Android и iOS (Capacitor)

Нужны Node.js 20+, Android Studio, а для iOS — Mac с Xcode (или облачная сборка, например Codemagic или Ionic Appflow).

1. В `capacitor.config.json` замените `appId` на свой, например `az.vashaorganizaciya.sdgoku`. После публикации идентификатор поменять нельзя.
2. Установите зависимости и добавьте платформы:
   ```
   npm install
   npx cap add android
   npx cap add ios        # только на Mac
   npx cap sync
   ```
3. Android: `npx cap open android`, затем Build → Generate Signed App Bundle (файл .aab для Google Play).
4. iOS: `npx cap open ios`, затем Product → Archive в Xcode.
5. После любой правки в `www/` выполняйте `npx cap sync`. Папки `android/` и `ios/` после создания добавляйте в репозиторий: в них хранятся настройки нативных проектов. Папки `android/` и `ios/` после создания добавьте в репозиторий: в них хранятся настройки подписи, иконки и версии приложения. Ключи подписи в репозиторий не кладите, они уже перечислены в `.gitignore`.
6. Иконка и заставка приложения: когда появится логотип, положите `assets/icon.png` (1024×1024) и сгенерируйте размеры пакетом `@capacitor/assets`.

Кнопка «Назад» на Android уже обрабатывается (плагин `@capacitor/app`).

## Сервер: вход по почте, синхронизация, общий рейтинг

1. Создайте проект в консоли Firebase и добавьте в него веб-приложение.
2. Authentication → Sign-in method → включите Email/Password.
3. Создайте Firestore Database и вставьте правила из `firebase/firestore.rules`.
4. Скопируйте конфиг веб-приложения в `www/js/config.js` вместо `firebase: null`.
5. Проверьте: Настройки → Аккаунт → «Войти по почте»; после победы результат появляется в «Рекорды → Общий рейтинг».

Как устроены данные:

- `users/{uid}`: прогресс игрока (статистика, рекорды, достижения, серия дней). При входе локальный и серверный прогресс объединяются, ничего не теряется.
- `leaderboards/{доска}/scores/{uid}`: лучший результат игрока на доске. Доски: `easy`, `medium`, `hard`, `expert`, `daily-ГГГГ-ММ-ДД`.

Что важно знать:

- Результат считает клиент, поэтому упорный человек может подделать рекорд. Правила базы отсекают только явно невозможные значения. Если рейтинг станет важным, проверку нужно переносить на сервер (Cloud Functions).
- Если на iOS вход «зависает» при запуске, уберите `authDomain` из конфига: для входа по почте он не нужен, а его загрузка в оболочке Capacitor иногда мешает. Запасной вариант — плагин `@capacitor-firebase/authentication`.
- Прогресс без аккаунта хранится в `localStorage` веб-оболочки. Для надёжности на iOS стоит перевести его на `@capacitor/preferences` (точка замены — функции `read` и `write` в `js/store.js`).

## Иконки ЦУР и правила ООН

- Сейчас в `www/assets/sdg/` лежат иконки, вырезанные из присланного постера (около 160 px). **Перед публикацией замените их официальными** из архива E-SDG-Icons-WEB на странице материалов ООН: https://www.un.org/sustainabledevelopment/news/communications-material/ . Имена файлов оставьте прежними.
- Иконки нельзя перерисовывать и изменять.
- Правила использования: https://www.un.org/sustainabledevelopment/wp-content/uploads/2023/09/E_SDG_Guidelines_Sep20238.pdf
  - Информационное некоммерческое использование разрешения не требует.
  - Реклама, платные функции, сбор средств: сначала письменное разрешение ООН (форма запроса есть на той же странице).
  - Организациям вне системы ООН нельзя использовать вариант логотипа с эмблемой ООН и нельзя объединять цветное колесо ЦУР или иконки с собственным логотипом. Это касается и будущей иконки приложения.
  - ООН просит размещать ссылку на https://www.un.org/sustainabledevelopment и текст о том, что материал не одобрен ООН. Сейчас в «Настройки → О приложении» стоит пересказ своими словами (ключ `about_text` в переводах). Перед публикацией вставьте туда официальную формулировку со страницы материалов ООН.
- Плитки сейчас на английском во всех языках интерфейса. Наборы на других языках можно подключить отдельными правилами в `css/app.css`, например `html[lang="ru"] .g1 { background-image: … }`.

## Чек-лист публикации

- Аккаунт разработчика (платная регистрация). Для личных аккаунтов, созданных после 13 ноября 2023 года, перед выпуском нужно закрытое тестирование: минимум 12 тестировщиков в течение 14 дней подряд. У аккаунтов организаций этого требования нет. Подробности: https://support.google.com/googleplay/android-developer/answer/14151465

- Раздел Data safety: адрес почты, идентификатор пользователя, игровой прогресс.
- Удаление аккаунта: в приложении уже есть (Настройки → Аккаунт), дополнительно нужна веб-ссылка для запроса на удаление.
- Возрастной рейтинг, описание и скриншоты на трёх языках.

App Store:

- Участие в Apple Developer Program (платная годовая подписка), Mac с Xcode или облачная сборка.
- Политика конфиденциальности и «этикетки» конфиденциальности в App Store Connect.
- Удаление аккаунта внутри приложения: есть.

Требования магазинов меняются, перед отправкой сверьтесь с актуальными.
